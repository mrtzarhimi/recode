Interpretation and provenance

Unchanged Day-0 transfer uses Day-0 normalization. Normalization-only uses Day-K training neural statistics, so it is target-calibrated and not zero-shot. NoMAD alignment uses target training data; validation may select its checkpoint.

Only the selected split is aggregated. Evaluation reports may select inlier trials and movement-onset windows from behavior; scores are therefore conditional on those eligible observations. No result is evidence of improvement by itself: compare the same target days, split, readout, and metric.
